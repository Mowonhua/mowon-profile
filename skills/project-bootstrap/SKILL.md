# 项目协作初始化

初始化项目协作配置，生成项目级 `AGENTS.md` 与文档维护配置，安装项目级 Skill。

## 执行范围

用户指定的目录是初始化目标。已有项目保留现行规则、用户文件和有效契约。只修改项目协作文件及其引用；依赖、运行配置、CI、远程环境和用户级配置按用户明确要求修改。

## 初始化流程

1. **识别项目。** 读取全局指令和目标及其父目录的 `AGENTS.md`，再检查项目简介、发布契约、构建入口和现有文档。确认项目根目录、技术栈、发布阶段与规则拥有者。
2. **确定生成范围。** 读取[适配规则](references/adaptation.md)，为每个生成文件确定目标路径。已有 `AGENTS.md` 或决策库时，再读[已有项目接入](references/existing-projects.md)。
3. **生成项目规则。** 根据 [AGENTS.md 模板](assets/AGENTS.template.md) 写入项目事实、命令和验证条件；按[项目地图](references/project-map.md)整理关键目录、模块职责与核心概念。按[全局与项目范围](references/adaptation.md#全局与项目范围)保留项目增量。
4. **生成文档与工作流配置。** 按[文档与工作资料配置](references/adaptation.md#文档与工作资料配置)适配三份项目规则，并安装项目 Skill。
5. **完成结构与内容检查。** 检查模板变量、相对链接、命令来源、Git 跟踪状态和全局规则的语义重复。按下方“完成条件”核对内容。
6. **交付配置。** 报告创建和修改的文件、已确认的命令、项目地图状态及仍缺少的项目事实。

模板中的 `{{变量}}` 应全部替换。命令或发布阶段未知时，按适配规则完成可确定的配置。

## 默认文件与按需文件

| 文件 | 生成时机 |
|---|---|
| `AGENTS.md` | 初始化时创建或合并 |
| `docs/AGENTS.md` | 初始化时创建或合并文档规则 |
| `.agents/notes/AGENTS.md` | 初始化时创建或合并决策规则 |
| `.agents/skills/maintain-agent-notes/SKILL.md` | 初始化时安装；已有同职能 Skill 时合并接入 |
| `.agents/skills/find-simplifications/SKILL.md` | 初始化时安装；已有同职能 Skill 时合并接入 |
| `.gitignore` | Git 项目需要排除本地临时产物时增补 |

## 完成条件

- 根 `AGENTS.md` 按发布阶段配置适用章节，已填写项目事实或明确缺项。
- 项目地图按实际结构写入，或保留写明补全时机的占位说明。
- 项目根与子目录的 `AGENTS.md` 只保存项目增量；全局指令已声明的约束没有重复。
- 兼容政策依据发布契约；命令依据项目入口和现有说明。
- 决策规则只有一个权威位置，所有入口明确读取条件。
- 文档维护流程位于所属 `AGENTS.md`，项目 Skill 已安装或接入，各入口的相对链接有效。
- 相对链接存在，生成文件没有模板变量，变更范围符合用户请求。

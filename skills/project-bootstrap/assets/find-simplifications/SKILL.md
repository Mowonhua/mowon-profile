# 查找可证实的简化

寻找能减少长期维护义务的改动。义务包括接口、数据表示、生命周期状态、配置路径、依赖、测试和文档。

## 确定范围与依据

读取[项目入口](../../../AGENTS.md)和目标目录的适用指令。按项目入口读取受影响领域的架构、测试约定与当前契约，再核对同一主题的活跃决定。

以用户给定的领域和目标确定范围。仅调查时输出候选；实施请求执行已授权的简化。尚未确定的产品取舍保留为候选。

## 调查流程

1. **追踪实际路径。** 查明生产者、转换、配置、消费者与可观察结果。
   同时核对动态注册、反射、生成入口、公开扩展点和外部消费者。
2. **寻找可减少的义务。** 用下方问题检查范围内的机制。
   为每个候选写出删除后消失的维护工作。
3. **核对保留理由。** 对照当前契约、决定与生产使用证据。
   区分无效实现、主动收窄能力、证据不足与应保留的义务。
4. **比较完整成本。** 比较被移除的系统与替代方案的全部成本。
   包括残留代码、依赖、测试、配置、文档和升级责任。
5. **整理候选。** 按下方候选说明写出证据、取舍与验收。
   每项候选应说明保留原方案的最强理由。
6. **完成任务分支。** 调查任务交付候选；实施任务完成已选改动与验证。
   报告覆盖范围、未决项和实际执行的检查。

## 寻找可减少的义务

- **功能是否有完整效果？** 检查值从哪里产生、在哪里读取、是否改变结果。字段到处传递不代表功能实际可用。
- **差异是否改变消费者动作？** 区分真正控制权限、持久性和职责的状态，与只增加无用选择的公开状态。
- **较窄的行为能否移除整个机制？** 指明放弃的能力与可删除的实现。已有生产消费者不自动排除候选，但能力损失应符合任务目标。
- **消费者能否按需读取权威值？** 检查重复历史、缓存、通知与恢复机制。先确认读取时点，再比较派生值或共享读取的方案。
- **配置与服务组合是否承担了多余策略？** 检查可选服务、提供方方法和显式调用是否已表达所需选择。保留职责或完成时点不同的操作。
- **替换后总成本是否下降？** 比较整个系统，包含适配代码和同步检查。移动复杂度或增加检查来维持重复定义，不算减少维护义务。

## 证据与保留条件

静态搜索无调用不能证明功能无用。测试和声明也不能单独证明生产路径存在。按项目实际入口核对安装、生成、加载与运行路径。

对异步与资源机制，逐项确认承诺、标志、取消、回调、清理和资源预留的拥有者与状态变化。只有表达同一事实的机制才可合并。

对校验、复制、冻结和缓存，确认值的来源、下一拥有者、校验位置和失效条件。保留契约要求的失败、时序、持久化与跨进程行为。

依赖替换应查明已有库或平台能力，并列出它真正删除的实现与专属测试。验证最可能不匹配的边界行为，以及替代后仍需维护的适配代码。

读取否决理由时，核对原条件是否仍成立。混合方案中的一项被否决，不代表其余独立项也无效。

测试简化应比较独立失败行为与替代覆盖。测试数量或运行成本不能单独决定去向。

## 候选说明与交付

每项候选包含以下内容，证据未知时明确列为缺口：

- 当前问题、拥有者与生产使用路径。
- 拟移除的机制、维护工作及仍需保留的部分。
- 给消费者带来的变化与放弃的能力。
- 真实备选方案，以及保留原方案的最强理由。
- 可观察的验收条件、风险和验证缺口。

材料归属按[文档与资料规则](../../../docs/AGENTS.md)选择。是否保存独立记录按[决策规则](../../notes/AGENTS.md)判断，并使用其维护入口完成关联记录检查。

文档与注释的裁剪按[文档维护规则](../../../docs/AGENTS.md#文档写作与维护)执行。实现变更按项目入口同步维护消费者、契约和派生产物，并选择能捕获目标回归的验证。

报告调查范围、可实施候选、保留项、待决项和实际证据。搜索尚未覆盖的路径应明确列出，避免把局部调查称为完整审计。

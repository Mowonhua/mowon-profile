# 验收清单

按 P0、P1、P2 顺序检查。

## P0：交互语义（应全部通过）

- [ ] 每个独立菜单面板只有一块共享层。
- [ ] 共享层带 `pointer-events: none` 和 `aria-hidden="true"`，条目不画独立的指针背景。
- [ ] 慢速从 A 移到 B：高亮是同一条视觉实体，位移连贯，收尾迅速。
- [ ] 快速划过 A 到 B 到 C：高亮直接改道，不排队，不闪回旧目标，不重新入场。
- [ ] 指针经过行间隙、分割线和面板 padding：高亮不闪断。
- [ ] 指针离开面板：高亮淡出。重新进入：高亮从有效位置出现。
- [ ] Tab、方向键、Home/End 和 typeahead 遵循基础菜单组件的语义；视觉高亮与真实键盘焦点指向同一条目。
- [ ] 指针指向、键盘焦点、选中、禁用四种状态各自正确；禁用项不出现共享层。
- [ ] 系统开启减少动态效果时没有滑行动画，焦点反馈依然清晰。

## P1：复杂菜单

- [ ] 有滚动条时，不可见条目不会成为指针目标；滚动造成的位移立即对齐。
- [ ] 面板带 scale 入场时，共享层没有倍数偏移。
- [ ] 条目显示、隐藏、过滤、动态添加、面板宽度变化和字体加载之后，共享层没有残留位置。
- [ ] 字重或图标粗细变化不影响行宽、面板宽度和右侧快捷键的位置。
- [ ] 子菜单持有独立图层，父子菜单的焦点和展开状态过渡正确。
- [ ] 模态对话框、Portal 和毛玻璃背景不导致共享层越界或遮挡命中区域。
- [ ] 共享层背景符合主题；危险操作和禁用条目的语义色不被共享层覆盖。

## P2：性能与可维护性

- [ ] 同一帧的多次 `pointermove` 只调度一次布局计算。
- [ ] `pointermove` 不触发 React 或 Vue 的整树重渲染。
- [ ] 监听器、`MutationObserver`、`ResizeObserver` 和 rAF 在卸载时释放。
- [ ] 高频操作下没有持续的同步布局抖动或大量重绘；需要结论时用浏览器 Performance 面板核实，不只按 CSS 属性名推断合成。
- [ ] 菜单库的角色、屏幕阅读器描述、焦点恢复和热键行为保持原样。

## 最小自动测试

以下六项覆盖共享层最容易退化的部分。断言目标位置、DOM 复用、状态和过渡规则；不要在 jsdom 里假设真实插值动画一定执行。

1. **单层身份不变**：连续两次 `pointermove` 后，同一个 DOM 节点的 `transform` 发生变化。
2. **间隙连续**：指针在菜单边缘、分割线和间隙上移动时，共享层保持可见。
3. **输入合帧**：同一帧触发五次 `pointermove`，只排队一次 rAF，最终采用最后一次坐标。
4. **键盘焦点**：切换 `data-highlighted` 或 `aria-selected` 后，共享层对齐最新条目，不改动已有的键盘选择。
5. **降级**：模拟减少动态效果时，`transform` 不产生过渡。
6. **无障碍**：共享层不进入 Tab 顺序，真实条目行的焦点和可访问性名称不受影响。

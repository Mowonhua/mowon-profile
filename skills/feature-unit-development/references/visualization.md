# 功能视图

功能视图从 `features/*.md` 实时生成。页面展示模块、功能、场景、实现位置、创建提交和直接功能关系。页面无需复制到目标项目。

## 启动

运行以下命令，将 `<skill-dir>` 和 `<project-root>` 换成实际路径：

```text
python <skill-dir>/scripts/view.py <project-root>
```

服务默认监听 `127.0.0.1:8765` 并打开浏览器。端口占用时，服务改用系统分配的端口。使用终端打印的实际地址。

- `--port 端口`：指定端口，`0` 表示系统分配。
- `--no-open`：仅启动服务，不打开浏览器。
- `Ctrl+C`：停止服务。

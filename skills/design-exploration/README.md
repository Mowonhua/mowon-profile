# design-exploration

A greenfield design-language exploration skill for AI coding/design agents.

It is intended for projects that do not yet have a mature visual identity. The skill guides the agent through:

1. Product/design brief formation
2. Design criteria
3. Reference research
4. 3–5 distinct visual directions
5. Switchable UI prototypes for every direction
6. Rendered direction comparison and user convergence
7. Selected-direction refinement and structured handoff
8. Delegated `DESIGN.md` creation through `design-creator`

## Install

Copy the `design-exploration` directory into the skills directory used by your agent harness.

Typical usage:

```text
Use design-exploration to establish the visual design language for this project from scratch, then call design-creator to produce DESIGN.md.
```

Or:

```text
We have no existing design system. Explore several substantially different visual directions, implement and show them as switchable UI prototypes, converge on a direction, then delegate DESIGN.md creation to design-creator.
```

# bots

Bot 的角色指令，以角色为单位各一份。

角色指令用于定义 Bot 的行为和能力。同一份角色指令可以被多个 Bot 共用。实例之间的差别只有工作目录和各自的记忆，指令本身不因项目而分叉。

## 写角色指令前的检查顺序

1. 先看 `system/AGENTS.md`，已有的一律不写。
2. 再看 `skills/project-bootstrap/assets/` 下的三份模板与两份项目 Skill，其中已有的一律不写。
3. 剩下的才是角色特有约束，通常落在职责边界、固定动作、异常处理这三类里。写不出这三类以外的东西，说明这一条不该放角色层。

## 命名与长度

目录名用 kebab-case 的角色标识，如 `development`、`review`、`research`。目录内只有一份 `INSTRUCTIONS.md`。

单份不超过 2KB，超过时与用户商讨该如何精简。
